# Urban Adventure refresh — implementation plan

Audit: React 18/Vite/TypeScript, Tailwind 3 semantic tokens and Radix primitives remain suitable. The existing Bricolage Grotesque is retained for all functional UI. V5's continuous planner, six categories, draft, Supabase services, extraction, collections, sharing and RSVP are working local paths and must not be rebuilt. Existing logo/PWA icons are provisional artwork; preserve their bytes until the designer supplies replacements. No Capacitor/Android project exists in this checkout.

Affected areas: `src/theme.css` (palette, typography roles, shared surfaces/interaction styles); a central brand configuration and reusable logo lockup; existing logo references in Home/Login/username/navigation/legacy Home; Home visual hierarchy, discovery cards and saved venue card presentation; narrowly scoped presentation classes in the planner. Documentation and one self-hosted display font with its licence are added. No package dependencies, routes, persistence logic, backend code, schema, credentials or migrations are changed for this refresh.

Plan: map the requested orange/pink/purple/cyan palette to semantic tokens with readable foreground pairs; add locally served Knewave only for short marketing headlines; keep branding artwork intact via a central asset map; update shared cards/navigation/buttons/sheets first; simplify Home hierarchy around real venues and existing actions; inspect both themes at mobile/desktop widths; run existing checks and verify main workflows against the disposable QA backend.

Regression risks: tokens affect every consumer, including status contrast and Stripe's existing token reader; replacing logo markup must preserve accessible app naming; card/photo layout must retain details/selection/edit actions; motion must remain optional; the 3×2 category grid and sticky planner indicator must keep working. Save/extraction and account/event services stay untouched. Hosted integrations and physical Android/iOS behavior cannot be certified by fixture/browser checks.
