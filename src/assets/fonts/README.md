# Font assets

Functional UI retains the existing Bricolage Grotesque variable WOFF2.

Knewave Regular is a separate, locally served display font for limited marketing headlines. Source: [Google Fonts Knewave directory](https://github.com/google/fonts/tree/main/ofl/knewave). Its [SIL Open Font License](https://github.com/google/fonts/blob/main/ofl/knewave/OFL.txt) is included in `public/licenses/KNEWAVE-OFL.txt` (copied into production builds); the original font is distributed without alteration as `knewave-regular.ttf` (32,460 bytes). No Google Fonts runtime connection or npm font dependency is needed. Use `font-display: swap` and keep decorative typography out of forms, controls and venue names.
